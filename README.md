# Modern Login Page
This is a modern, elegantly designed login page enhanced with smooth animations. It allows users to log in and also sign up directly from the same interface.

## Note:
This project is intended for desktop use only, and therefore does not include responsiveness for smaller screen sizes.

## 🚀 Live Demo
You can view Modern Login Page here 👉 [Click to Visit](https://code-mo-dev.github.io/Modern-Login-Page/)

## 📋 Front-End Technologies

### 1. HTML5
- Building basic page structure
- Using Semantic HTML

### 2. CSS3
- User interface design
- Responsive Design
- Animations and Transitions
- Flexbox and Grid Layout

### 3. SCSS 
- Advanced CSS processor
- Modular SCSS structure


### 4. JavaScript (ES6+)
- Adding interactivity to the page
- DOM Manipulation
- Event Handling

## 📚 External Libraries & Tools

### 5. Font Awesome
- Icon library
- File: `all.min.css`
- Usage: `fa-brands`, `fa-solid`

## 🛠️ Build Tools & Development

### 6. Prepros
- Project build and compilation tool
- Compiling SCSS to CSS
- Auto-compilation
- Live Reload

### 7. CursorAi
- Used to enhance code quality and speed up the development process
- Helped in generating repetitive code sections to save time
- Assisted in detecting errors and providing useful suggestions during coding
- Utilized for code refactoring, especially in CSS and JavaScript files
- Supported me with ideas for UI design and improving the overall user experience
